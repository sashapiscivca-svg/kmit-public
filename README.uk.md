# Kmit

[![CI](https://github.com/sashapiscivca-svg/kmit-public/actions/workflows/ci.yml/badge.svg)](https://github.com/sashapiscivca-svg/kmit-public/actions/workflows/ci.yml) [![Ліцензія коду: PolyForm NC 1.0.0](https://img.shields.io/badge/code-PolyForm%20NC%201.0.0-blue)](LICENSE) [![Ліцензія вмісту: CC BY-NC-SA 4.0](https://img.shields.io/badge/content-CC%20BY--NC--SA%204.0-lightgrey)](LICENSE-CONTENT.md)

[English](README.md) · **Українська**

Kmit це офлайн-помічник для навчання українських школярів 5–12 класів за програмою Нової української школи (НУШ). Він пояснює тему, дає підказки, які ніколи не видають відповіді, і розкладає повторення за інтервалами. Усе, що робить дитина, лишається на пристрої в зашифрованому вигляді. Застосунок не має дозволу на мережу, реклами, аналітики й облікових записів. У тому самому застосунку є окремий профіль вчителя з роботами для друку й бібліотекою уроків, а окрема збірка для методистів дає змогу вичитувати вміст.

Інтерфейс і весь навчальний вміст українською мовою.

> [!WARNING]
> **Стан: пре-альфа. Ще не готово для використання з дітьми.**
> - Android-застосунок зібрано й перевірено лише автоматичними тестами та в браузері на комп'ютері. **На справжньому телефоні (чи емуляторі) він ще жодного разу не запускався.**
> - **Увесь навчальний вміст створено за допомогою ШІ-агентів** і перевірено автоматизованою «сліпою» перевіркою ключів. **Методисти-люди його ще не вичитували, тож він може містити фактичні чи методичні помилки.** Кожен пакет вмісту має статус `draft` («чернетка»); зараз ця позначка видна лише в бібліотеці уроків учителя, дітям вона не показується.
> - Вміст є **лише для 5–7 класів**. Математика є лише для 5 класу. До 8–12 класів ще не бралися (застосунок показує їх як «готуються»).

## Можливості

- **Уроки, а не лише тести.** У кожної теми є короткий урок: текст, розв'язані приклади, що відкриваються покроково, питання для самоперевірки й власний конспект дитини.
- **Підказки, які навчають.** Драбина підказок, далі аналогічний розв'язаний приклад з *іншими* числами, далі «запитай дорослого». В обчислювальних задачах (математика) відповідь і проміжні результати дитині ніколи не показуються; це забезпечує код, а не домовленість (див. [інваріанти](ARCHITECTURE.md#invariants)). У предметах із фактичними знаннями правильна відповідь із поясненням показується після власної спроби дитини.
- **Адаптивна практика.** Детермінований рушій оцінює опанування (Bayesian Knowledge Tracing з фіксованими параметрами), обирає посильне, перемежовує теми й розкладає повторення за зростаючими інтервалами.
- **Генератори математики.** Завдання з математики 5 класу створює код на Rust із точним обчислювальним оракулом (35 навичок), тож ключ обчислюється, а не пишеться вручну.
- **Мотивація без тиску.** Скінченний альбом наліпок і свій «світ» істот для кожного класу, піксельний герой, «лінійка тижня» за старанність. Нагороди лише додаються, ніколи не відбираються й не залежать від швидкості. Свято переходу до наступного класу ніколи не блокує перехід чи повернення назад.
- **Профіль вчителя.** Роботи для друку (самостійна, контрольна, домашня, у форматі НМТ) до 4 варіантів із ключем, бланком відповідей і картками для розрізання (PDF); диктанти й завдання з пропусками для мовних тем; план уроку на 45 хвилин і пам'ятка для учнів; бібліотека уроків із пошуком і закладками; тематичний план для друку. Профіль вчителя не містить даних учнів.
- **Застосунок методиста.** Окрема збірка «Kmit Методист»: до кожного тексту позначка «усе гаразд», виправлення або «прибрати завдання», потім один CSV-файл, який `content-tools apply` вносить у пакети.
- **Вміст як дані.** Уроки й банки завдань зберігаються в JSON-пакетах (`kmit-pack-1`). Новіші підписані пакети (Ed25519) можна встановити з файлу без перевстановлення застосунку.
- **Доступність.** Масштаб шрифту, «менше руху», світла («папір») і темна («дошка») теми, озвучення синтезатором Android (на пристрої ще не перевірено).

## Принципи приватності

- **Без мережі.** Маніфест Android вилучає `INTERNET`. `compliance_tests` падають, якщо з'являються дозволи `INTERNET`, `AD_ID`, геолокація, камера, мікрофон, контакти тощо, якщо додано рекламні чи аналітичні бібліотеки або якщо інтерфейс посилається на зовнішні адреси.
- **Зашифроване локальне сховище.** Кожен профіль це база SQLCipher, випадковий 256-бітний ключ якої обгорнуто двічі: ключем із PIN (Argon2id) і одноразово показаним кодом відновлення. Видалення профілю знищує обгорнуті ключі (крипто-стирання). Резервне копіювання Android вимкнено; знімки екрана за замовчуванням заборонено.
- **Мінімум даних.** Профіль дитини зберігає нікнейм і номер аватара; прізвища, школи, фото чи дати народження немає. До 4 профілів на пристрої.
- **Дані дитини ніколи не передаються вчителю цифровим шляхом.** Дитина може надрукувати чи зберегти аркуш і показати його особисто. Профілі вчителя й дитини не мають доступу до даних одне одного, імпорту дитячих робіт немає.
- **Без реклами, аналітики, облікових записів, покупок і чатів.**

Політика конфіденційності (чернетка): [українською](docs/legal/privacy-policy.uk.md) · [English](docs/legal/privacy-policy.en.md).

## Швидкий старт для розробників

Потрібні: стабільний Rust (мінімальна версія 1.80; CI використовує актуальний stable), компілятор C, `perl` і `make` (SQLCipher і OpenSSL компілюються з вихідного коду), Node.js ≥ 22 для перевірки інтерфейсу, Chromium чи Chrome для наскрізних тестів.

```bash
git clone https://github.com/sashapiscivca-svg/kmit-public.git
cd kmit

# Запуск застосунку в браузері на комп'ютері (те саме ядро на Rust, що й на Android)
scripts/dev.sh                     # потім відкрийте http://127.0.0.1:8765/
                                   # дані: ~/.local/share/kmit-dev (змінна KMIT_DATA; порт: PORT)

# Перевірки (ті самі, що в CI)
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
scripts/check_ui.sh                # синтаксис JS і відсутність можливостей, яких не знають старі Android WebView

# Наскрізні тести інтерфейсу в headless Chromium
CHROME=/шлях/до/chrome THEME=light scripts/e2e.sh
CHROME=/шлях/до/chrome THEME=dark  scripts/e2e.sh
CHROME=/шлях/до/chrome scripts/e2e-reviewer.sh
```

`scripts/dev.sh` запускає `dev-server`: невеликий HTTP-сервер на стандартній бібліотеці Rust, який слухає лише 127.0.0.1 і передає команди інтерфейсу ядру. Це інструмент розробника, а не частина продукту. Скрипти викликають Cargo з `--offline`, тож після клонування один раз виконайте `cargo fetch`. Докладніше про перевірку: [docs/how-to-test.md](docs/how-to-test.md).

### Android

Android-застосунок це оболонка Tauri 2 (`app/src-tauri`). Для збірки потрібні Android SDK і NDK, JDK 17 і `tauri-cli`. Версії інструментів, налаштування середовища, підпис і перевірку відсутності дозволу `INTERNET` описано в **[BUILDING.md](BUILDING.md)** (англійською, з українським підсумком на початку).

## Вміст і як він створюється

| Клас | Предмети з вмістом | Тем (у кожної урок) |
|---|---|---|
| 5 | Математика (генеровані задачі), українська мова, українська література, англійська мова, історія, природознавство, інформатика | 134 |
| 6 | Українська мова, українська література, англійська мова, історія, біологія, географія, інформатика | 136 |
| 7 | Українська мова, українська література, англійська мова, історія, біологія, географія, фізика, хімія, інформатика | 176 |

Разом: 446 тем, 10 886 завдань із вибором і 444 завдання з введенням слова у 23 пакетах, а також генеровані задачі з математики 5 класу. Ще немає: математики для 6–7 класів, завдань із введенням слова для 6–7 класів і будь-якого вмісту для 8–12 класів.

Конвеєр, чесно:

1. **Чернетка.** ШІ-агенти складають план теми за чинною програмою, потім урок і 26–30 завдань на тему, кожне з трьома підказками й поясненням. Тексти підручників не копіюються.
2. **Лінт.** `scripts/pack_lint.py` і `cargo test -p subjects` перевіряють структуру, довжини, читабельність, те, що підказки не називають відповіді, і нейтральні до статі формулювання.
3. **Сліпа перевірка ключів.** Окремий агент відповідає на кожне завдання з вибором, не бачачи ключа (`scripts/blind_quiz.py`); кожну розбіжність розглянуто, а завдання виправлено там, де помилявся ключ. Для математики 5 класу ключ натомість обчислює оракул на Rust.
4. **Злиття.** `scripts/pack_merge.py` збирає пакет, запускаються тести.
5. **Вичитка людьми: ще не зроблено.** Методисти вичитують вміст у застосунку методиста; `content-tools apply` і `approve` змінюють статус пакета з `draft` на `reviewed` чи `approved`. **Жоден пакет ще не пройшов цього етапу.**

Кроки 1–4 зменшують кількість помилок, але не замінюють фахівців-предметників. Якщо ви знайшли помилку, відкрийте issue за шаблоном «Помилка у вмісті». Формат і процес: [docs/content-packs.md](docs/content-packs.md), [docs/review-workflow.md](docs/review-workflow.md), [docs/reviewer-app.md](docs/reviewer-app.md).

## Як долучитися

Внески в код і вміст вітаються, особливо вичитка вчителями й методистами-предметниками. Спершу прочитайте [CONTRIBUTING.md](CONTRIBUTING.md): кожен коміт потребує підпису DCO (`git commit -s`), а внесок надається на описаних там умовах. Ніколи не додавайте до репозиторію даних дітей, PIN-кодів, кодів відновлення чи ключів підпису. Проєкт дотримується [Кодексу поведінки](CODE_OF_CONDUCT.md).

- Помилки застосунку: відкрийте issue (без даних дітей).
- Помилки у вмісті: шаблон issue «Помилка у вмісті».
- Проблеми безпеки чи приватності: **не відкривайте публічного issue**, див. [SECURITY.md](SECURITY.md).
