# Кабінет вчителя: що вже є і що покращувати далі

Принцип: учитель і дитина працюють по-різному; дані дитини вчителю цифровим шляхом не передаються (лише папірець). Усе нижче перевірено на сумісність із цим принципом.

## Є (2026-10-09)
- **Роботи**: самостійна, контрольна, домашня, НМТ; до 4 варіантів; PDF завдань, ключа й бланка з клітинками; повторення роботи з історії (те саме зерно дає ті самі варіанти).
- **Бібліотека уроків**: усі уроки всіх класів і предметів (включно з математикою) для читання з правильними відповідями й ключовими ідеями; **пошук по всіх уроках** (назва, поняття, абзаци); **закладки**; перехід до всіх завдань теми.
- **Матеріали для друку**: план уроку на 45 хв; **пам'ятка для учнів** (поняття, правило, запитання для конспекту).
- **Вичитка** для методистів винесена в окремий застосунок «Kmit Методист» ([reviewer-app.md](reviewer-app.md)); у вчительському профілі її немає. У бібліотеці уроків учитель бачить статус перевірки пакета («Чернетка: ще не перевірено методистом»).

## Зроблено в другій хвилі (пп. 1-7 нижче)
Рівні складності (орієнтовно за формою умови; для математики не діють), великий шрифт, повторення з попередніх класів, тематичний план (PDF), диктант і завдання з пропусками (теми із введенням слова), картки для розрізання, експорт зауважень однієї теми.

## Пропозиції (за цінністю й дешевизною; пп. 1-7 вже зроблено)
1. **Рівні складності роботи** (повторення / застосування / НМТ-аналіз): потребує позначок складності в банках; зараз їх немає. Дешево для математики (генератори), для банків потрібні теги.
2. **Варіант великим шрифтом і розрідженим інтервалом** для учнів із особливими потребами: параметр PDF, не потребує даних.
3. **Повторення попереднього класу**: робота з тем 5 класу в 6 класі (вибір теми з іншого класу в одну роботу).
4. **Тематичний план на семестр**: вчитель обирає послідовність тем і друкує план із орієнтирами очікуваних результатів (плани одиниць вмісту треба перенести в пакети як метадані).
5. **Словникові диктанти й завдання з пропусками** для мов (з банків «typed»): нові типи робіт.
6. **Мінімізація паперу**: кілька коротких карток-завдань на аркуш (розрізати).
7. **Експорт власних зауважень по темі** окремо від загальної вичитки.
8. **Перевірка робіт у клітинках (T5)**: спершу вимірювання на дитячому письмі (`docs/spikes/t5-digit-cells.md`).
9. **Двомовні матеріали (кримськотатарська, угорська, румунська)**: після відповідних пакетів і рецензентів-носіїв мови.

## Не робимо (суперечить принципам)
Імпорт аркушів дітей, QR/Bluetooth-обмін, облікові записи, серверна синхронізація, аналітика використання кабінету.
