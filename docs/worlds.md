# Світи істот за класами й свято переходу

## Що це
У кожного класу 5–12 свій світ істот і своя колекція:

| Клас | Світ | Вигляд істот |
|---|---|---|
| 5 | Лісова галявина | звірята з вушками |
| 6 | Море й берег | плавці, щупальця, бульбашки |
| 7 | Гори й небо | крила, чубчик, ніжки |
| 8 | Печери й кристали | ріжки, шипи, самоцвіти |
| 9 | Пустеля й оазис | горби, довгі ніжки, сонце |
| 10 | Космічна подорож | антени-очі, «блюдце», зорі |
| 11 | Полярне сяйво | пухнасті з бурульками, сніг |
| 12 | Вершина (підготовка до НМТ) | вогняні птахи з чубчиком і крилами |

Свято переходу між класами працює для всіх пар сусідніх класів 5→6, …, 11→12; воно пропонується й доступне, щойно в наступного класу з'являється вміст (поки вмісту немає, екран чесно каже «клас готується»). Тому щойно агенти наповнять 8–12 класи, свято й світи вже чекають. Істоти малюються програмою за ідентифікатором теми (піксельна сітка 8×8), тому нових малюнків від художника не потрібно.

Нагороди (опанування, наполегливість, самовиправлення, прохання про підказку), правила альбому й «нічого не відбирається» не змінилися: світ лише вигляд.

## Свято переходу
- Пропозиція на головній, коли в класі опановано ≥ 80 % тем (`ceremony::PROMOTE_PERCENT`) і наступний клас має вміст. Перехід на сусідній клас з екрана «Класи» теж іде через свято.
- Екрани: підсумок класу й парад істот → новий світ і стартова істота (подарунок без умов) → вітання й свідоцтво (PDF) → головна.
- **Перехід нічим не блокується**: свято можна пропустити («Ще побуду в N класі»), перейти раніше, повернутися назад (екран «Класи»); нагород за свято немає (інваріант «нагорода не за дарма»).
- Свято фіксується один раз на клас (`AppState::ceremonies`); свідоцтво доступне з колекції.

## Де що живе
| Що | Де |
|---|---|
| Список світів і назви | `crates/app-core/src/catalog.rs` (`WORLDS`, `world_of`) |
| Малюнок світу | `app/ui/worlds.js` (`WORLD_STYLE`, `decorate`) |
| Логіка свята | `crates/app-core/src/ceremony.rs`; команди `ceremony_status`, `ceremony_do`, `ceremony_pdf`, `album {grade}` |
| Екран свята | `app/ui/ceremony.js` |
| Свідоцтво | `crates/report/src/styled.rs` (`certificate_pdf`) |
| Тести | `crates/app-core/tests/ceremony_tests.rs`, e2e «Свято переходу» в `app/e2e/run.mjs` |

## Як додати світ для нового класу (8, 9, …)
1. `catalog.rs`: додати рядок `(8, "id", "Назва світу")` до `WORLDS` і збільшити розмір масиву. Для класів 5–12 світи вже є; рядок потрібен лише для класів поза цим діапазоном (на майбутнє), для них світ береться по колу.
2. `app/ui/worlds.js`: додати `WORLD_STYLE.<id>` (колір відтінку тіла, фон колекції, колір рота, прикраси) і гілку `decorate` для нового вигляду (верх, боки, низ; ядро 3–5 рядків лишається).
3. `app/ui/style.css`: клас `.w-<id>` з кольором фону.
4. Оновити тест `every_grade_has_its_own_world_…` у `crates/app-core/src/ceremony.rs`.
5. Перевірити вигляд: відкрити колекцію класу в `scripts/dev.sh` й подивитися кілька істот різних предметів (мають відрізнятися від сусідніх світів силуетом, не лише кольором).

Правила: без блимання й різких рухів (анімації вимикає «менше рухів»), назви світів дитячі й нейтральні за статтю, текстовий опис кожної істоти для читалки екрана вже є в альбомі.
